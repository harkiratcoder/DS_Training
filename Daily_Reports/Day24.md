# Day 24 – Exploratory Data Analysis

## Objective
To understand relationships and patterns within the hospital patient dataset.

## Work Done
- Performed exploratory data analysis using Pandas and visualization libraries.
- Studied distributions of important patient attributes.
- Analyzed relationships between patient characteristics and hospital stay.
- Examined department-wise and severity-related patterns.
- Created visualizations to identify trends and variations.
- Used the findings to understand potentially important predictive features.

## Key Learning
Learned how exploratory data analysis can reveal meaningful patterns and guide feature selection and model development.
