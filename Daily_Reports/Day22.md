# Day 22 – Dataset Understanding

## Objective
To perform an initial understanding of the hospital patient dataset.

## Work Done
- Loaded the dataset using Pandas.
- Examined the number of records and features.
- Inspected column names and their data types.
- Studied categorical and numerical attributes.
- Checked the distribution of the target variable.
- Identified the different patient stay categories.
- Used descriptive statistics to understand the dataset.

## Key Learning
Learned how dataset profiling helps identify the structure, characteristics, and potential issues in a machine learning dataset.
