# Day 25 – Feature Engineering

## Objective
To prepare and transform features for machine learning models.

## Work Done
- Reviewed the available input features.
- Identified categorical features requiring encoding.
- Applied appropriate encoding techniques to categorical variables.
- Prepared numerical and encoded features for model training.
- Created and stored the feature-column structure required during prediction.
- Ensured consistency between training and future prediction data.

## Key Learning
Learned how feature engineering and consistent preprocessing improve the reliability of machine learning pipelines.
