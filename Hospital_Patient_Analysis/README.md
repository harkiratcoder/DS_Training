# 🏥 Hospital Patient Analysis & Insights Dashboard

## 📌 Overview
An end-to-end Data Science project that analyzes hospital patient records to discover trends in patient demographics, diseases, admissions, and hospital revenue.

The project covers the complete Data Science lifecycle:
- Data Collection
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- SQL Analysis
- Machine Learning
- Interactive Dashboard
- Deployment

---

## 🎯 Objectives

- Analyze patient demographics
- Identify common diseases
- Analyze monthly admissions
- Study department performance
- Predict hospital bills
- Predict patient length of stay

---

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- SQLite
- Scikit-learn
- Streamlit
- Git & GitHub
