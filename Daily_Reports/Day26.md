# Day 26 – Machine Learning Model Training

## Objective
To train machine learning models for predicting patient hospital stay categories.

## Work Done
- Prepared training data and target labels.
- Split the processed dataset into training and testing data.
- Implemented machine learning models for the prediction task.
- Trained a Decision Tree based model.
- Trained an XGBoost based model.
- Generated predictions using the trained models.
- Compared the model outputs for further evaluation.

## Key Learning
Learned the practical workflow of training multiple machine learning models for a real-world classification problem.
