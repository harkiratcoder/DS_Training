# Day 23 – Data Cleaning and Preprocessing

## Objective
To prepare the hospital patient dataset for machine learning.

## Work Done
- Checked the dataset for missing values.
- Identified duplicate and inconsistent records.
- Examined categorical values for inconsistencies.
- Performed appropriate data cleaning operations.
- Converted data into a machine-learning-compatible format.
- Prepared the cleaned dataset for further analysis.
- Saved the processed dataset for reuse.

## Key Learning
Learned the importance of data quality and preprocessing before applying machine learning algorithms.
